# 「흙수저 김토토」 그림 제작 지침 (Codex용)

이 폴더는 인스타그램 릴스 직장인 드라마 「흙수저 김토토」의 제작 자료다. 그림을 만들어 달라는 요청을 받으면 아래 규칙을 따른다.

## 하는 일

1. 요청에 적힌 그림 목록을 **위에서부터 한 장씩** 만든다.
2. 각 그림은 요청에 적힌 프롬프트를 그대로 쓰고, "첨부"에 적힌 그림을 참조 이미지로 넣는다.
3. 완성한 그림을 요청에 적힌 경로(`assets/ep<화 번호>/<그림 번호>.png`)에 저장한다.
4. 한 장을 저장할 때마다 아래 "검수"를 하고, 통과하지 못하면 최대 두 번까지 다시 만든다.
5. 끝나면 만든 파일, 건너뛴 파일, 검수를 통과하지 못한 파일을 표로 보고한다.

그림 생성 도구를 쓸 수 없는 환경이면 아무것도 만들지 말고 그 사실을 먼저 알린다. 글로 된 설명이나 임시 그림으로 대신하지 않는다.

## 그림 규칙

- 세로 9:16.
- 인물은 흙빛 피부의 3D 애니메이션 캐릭터, 평범한 머리카락, 정수리에 식물. 배경은 사실적인 한국 일상 공간.
- 인물의 얼굴, 피부색, 머리 모양, 머리 위 식물, 옷은 참조 그림과 같아야 한다.
- 직급은 위로 솟은 식물 크기로 구분한다: 사원 새싹 하나 → 대리 묘목 → 과장 어린 나무 → 차장 중간 나무 → 부장 큰 나무. 한 장면에 여러 명이 나오면 이 순서가 지켜져야 한다.
- 김토토는 1~2화(입사 전)에는 새싹이 없고 삐친 머리 한 가닥만 있다. 사원증을 받은 뒤부터 새싹 하나.
- 얼굴과 글자는 화면 맨 아래 20%와 오른쪽 아래 구석을 피한다 (릴스 버튼에 가려진다).
- 실제 기관명, 실제 지명, 실제 서비스의 로고와 화면 구성은 쓰지 않는다. 기관은 "한국자연공사 나무읍지사", 포털·지도는 "네이놈".
- 프롬프트에 적힌 글자 외의 글자는 넣지 않는다. 워터마크를 넣지 않는다.

## 검수 (한 장마다)

- 참조 그림과 같은 인물로 보이는가 (얼굴, 머리, 식물, 옷)
- 식물 크기 순서가 직급과 맞는가
- 한글이 프롬프트에 적힌 그대로인가 (한 글자라도 다르면 다시 만든다)
- 얼굴이나 글자가 아래 20%, 오른쪽 아래 구석에 걸리지 않는가
- 같은 장소의 앞 컷과 방, 옷, 조명이 이어지는가

## 하지 않는 일

- **이미 있는 파일을 덮어쓰지 않는다.** 같은 이름이 있으면 건너뛰고 보고한다. 다시 만들라는 말이 명시된 그림만 새로 만들고, 그때는 기존 파일을 `<번호>_old.png`로 남긴다.
- `assets/characters/` 의 확정 인물 그림은 고치지 않는다.
- 대본(`02`, `06` 문서)과 프롬프트 내용을 임의로 바꾸지 않는다. 프롬프트가 규칙과 어긋나 보이면 만들기 전에 물어본다.
- 커밋과 푸시는 요청받았을 때만 한다.
